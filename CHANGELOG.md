# Changelog

Every release, read end to end. The record of record is the
[releases page](https://github.com/SirAllap/agentglass/releases) — each tag
carries its own notes, the desktop installers and the phone's `.apk`.

## Where this is going

The [Roadmap in the README](README.md#-roadmap), and the discussion behind it in
[#172](https://github.com/SirAllap/agentglass/issues/172). It used to be copied
here as well, and the two fell apart: the copy never gained the items added to
the README, and the README never carried two open ones from the copy. One list,
kept in one place.

## Released

- **v0.19.0** — **A workspace for coding agents, and a browser they can drive.** agentglass started as a glass to watch agents through and has become the place they work in: the terminal groups its tabs by project and folds the other projects into chips, a window switcher puts what is waiting for you first, every tmux tab says what its agent is doing, and the landing page and README now lead with that rather than with a dashboard. The built-in browser is the other half: an agent gets an isolated container of its own, read verbs that answer as data instead of as a picture, and a way to hand the tab to the person for the one thing only they can do.
  - **The browser answers an agent in data.** `observe --delta` returns only what changed since the last look, `checkup` answers "did it break?" in one call with load errors included, `html --clean` returns markup a model can read with the same ids `observe` uses, and `vitals` and `a11y` return measurements rather than screenshots. Click and press wait for what they caused and say what it was; an element can be acted on by what it is called, without a look first. Acts carry a real user activation, so a page that only accepts a gesture accepts them, and `handoff` gives the tab to the person for a CAPTCHA, a two-factor code or a consent screen. `AGENTGLASS_MCP_TOOLS=core` shrinks the tool list an MCP client re-reads every turn.
  - **A signed-in session comes over from a Firefox-family profile.** `session import` brings cookies and per-origin `localStorage`, aligns the user agent with the browser it came from — without that, a site accepts page reads and refuses an upload — and `session verify` names a copied session the site rejected instead of leaving an agent to find out on a login page.
  - **The bell speaks up only when an agent is blocked on you.** Every other kind of notification has its own switch in Settings, the popup, the bell, the chip and the chime obey the same settings, and the popover never pins itself open. A held tool call can be allowed or denied from the bell itself. Tool approval can also be a rule: a denylist hit is refused, an allowlist hit is allowed without a click, a parent's deny binds its children, one checkout's rule never allows in another checkout of the same repository, and a rule's decision is written in one transaction.
  - **Restoring a workspace no longer trusts a recycled pane id.** tmux reuses pane ids across servers and restarts, and a note keyed by the id alone was read back onto the wrong pane. Notes are keyed per server now, an older build installed afterwards reads the pane's current conversation, a closed tab stays closed, and the test suite refuses to migrate a database that is not its own.
  - **Review a local diff and send it to the agent in that tree.** Comment on a line or a hunk, collect the comments in a tray, and send the review as one prompt; it opens a terminal session in the right checkout and is kept until the terminal has actually received it. The fleet shows each session's worktree and branch and flags two live sessions sharing one working tree. The merge box lists every reason a pull request will not merge, ranked, after reading what the base branch demands.
  - **The phone was reworked screen by screen.** A bar of four peers — Terminal, Pull requests, Issues, Tasks — that opens where it was left, a terminal that is one surface titled by its checkout, pairing in three steps, checks in bands with a log that points at the failure, and a held gate whose "waited" keeps counting.
  - **Elsewhere**, the project picker lists projects from the folders you added and can start empty; the plugin catalogue pins what it lists; providers get worker roles; fleet search honours the time window and the provider chip; OpenAI's 5.x models keep distinct labels, so rate tiers no longer merge into one slice; a read-only MCP tool reports a session's spend under a response-size ceiling; and the pull-request board has one unread switch, filters that survive a restart, and approvals that know when a review was requested again.

- **v0.18.0** — **a plugin market you can read, and the checks around it that hold.** The plugins page led with a JSON URL and a Remove button beside it: the plugins themselves were behind a click on that address, one already installed was offered again as if it were not there, and the rest of the card was a box asking for somebody else's list. It is **one market** now — this project's own, read on sight, with a search box that is always there and a row of types taken from the words each author filed their plugin under, counted over what is left to take rather than over the document. **Details** opens the whole entry in place: the description unclipped, every surface it draws on, and the exact git source with its ref, which is the sentence Install acts on and not the same thing as a name in a list. The routes that added and removed lists are deleted rather than hidden, because a door the screen no longer draws is still a door. A plugin also says what it can do before it is switched on, and its settings live on its own page inside Plugins.
  - **The comment a submission gets could be forged, and now cannot.** That comment is built from a stranger's repository and ends with a machine-readable verdict, and only the quoted line of a finding had ever been treated as untrusted. Measured: a manifest whose `publisher` ended in a second marker wrote "the check passed" ABOVE the real answer, in the public thread a maintainer reads to decide. Every value is defused on its way in now — defused, not deleted, so a maintainer still sees what was put in the field — and the list shows one of EACH KIND of finding before filling up to twelve, because findings arrive sorted by name and a dozen of one kind used to push the one worth reading off the bottom under a count that said thirteen.
  - **What a submitter meets first was red before anything was wrong.** Opening the issue fires two events — the second is the template applying its own label — and the first run was cancelled mid-clone, so the job that comments failed on a report nobody had uploaded. The runs queue now, a label event counts only when it is that label (a maintainer applying `approved for listing` used to re-run the whole check), and the answer is **one comment, rewritten in place** rather than a thread of them. And a scan that did not run no longer reads as a scan that found nothing: the tick was printed whenever the findings list was empty, which is also what a crashed scanner looks like from there.
  - **The scan reads a path built a piece at a time, and three things it could not see before.** A plugin that appends to `~/.bashrc` was refused and one that rewrites an agent's settings file was not: a path assembled component by component never contains `.claude/settings` as contiguous text. Naming that directory at all is the finding now, agentglass's own config directory stopped being the one place the write check ignored, and an allowed host has to END where the allowlist says it does. Added, after reading a larger marketplace's scanner beside ours: a **compiled file committed into the repository**, found by reading four bytes rather than text, because a binary has no line to quote and is the one thing in a submission that cannot be reviewed by reading it; **code fetched at install time from a reference that can move**, refused only when it is unpinned, since otherwise the thing audited is not the thing run; and **something that installs itself to start on its own**. "Starts an agent" also stopped firing on the word `claude` in prose, which every plugin for this app says in its README — a costs list that overstates is one a reader learns to skip.
  - **A project removed from the picker is removed everywhere.** It was removed from the picker and nowhere else: the Diff view still grouped its changes, the checkout dropdowns still offered it, and every panel that asks who is on this machine still listed it — a button that removed the row it was on and nothing more. The picker still sees them, because it is the only place one can be put back, and the open project is never dropped whatever the list says.
  - **Pull requests and issues can be scoped to a repository** when the window is not scoped to one. An open fold lines up with the rows around it rather than sitting indented and pressed against its own header. A plugin card that grows no longer drags the card beside it to the same height. The accent row says whether it is following the theme or holding a colour somebody chose.
  - **A pane older than the last restart can drive the browser again.** The token reaches a pane once, in the environment it is opened with, and the app makes a new one when it restarts — so every panel older than that restart answered `unauthorized` with nothing to act on, and the workaround people reach for is digging the current value out of another process. The CLI reads the token the app wrote, after the one it was given is refused, and says which two it tried when neither works.
  - **Two of the thirteen drawers the understudy files decisions in were not the ones they said.** One could never be reached at all: its words were a subset of an earlier drawer's, and the first drawer that claims a line wins. The other was about stopping while its label was about merging, and it carried the Spanish word for "for", which claims every line containing it. The bank is re-filed once to match, on the exact text each row was classified by, with a test that fails for a class nobody has broken yet — the next time somebody widens the words of the class above it.

- **v0.17.0** — **the app stops arguing with the things it borrows.** A pull request GitHub will merge is mergeable here: `UNSTABLE` is its word for "mergeable, with non-required checks failing or running", and treating everything but `CLEAN` as blocked meant one failing optional job disabled a button GitHub had live — captioned with that job's own name. One definition now, asked by the overview, the rail and the verdict ladder alike, and the red job is still named, so merging past it is allowed rather than silent. A **tracker column is drawn in the order the tracker keeps it**: the API returns a list in descending `orderindex` while the tracker's page draws it ascending, and the board lifted the flagged cards on top of that, which the page does not do — the order is carried as the string it arrives as and compared as a decimal, because the scheme inserts a card by halving the gap to its neighbour and two that collapse to the same double sort at random. And **a card's description is read rather than scanned**: prose type, more leading, room around the headings, paragraphs that reflow to the pane instead of keeping the line endings of whatever editor hard-wrapped them.
  - **The pointer decides what Ctrl+ zooms, and it was answering wrong.** One gesture, three targets — the terminal's font, the page in the browser, the window everywhere else. The workspace keeps every view mounted and hides the inactive ones with `visibility: hidden`, deliberately, since `display: none` measures a terminal at zero and reflows it to a single column; a hidden box keeps its layout, so the browser's guest held a full-size rectangle behind whatever view was up and a rectangle was the whole test. Ctrl+ on the task board raised "Page 230%", the app never grew, and the browser was found at 350% the next time it opened.
  - **The mouse's back button leaves a pull request.** It means "back to where I was" everywhere else on the machine and meant nothing here, and it never reaches the page at all: the shell receives it as an app command, so a listener in the document waits for something that is never dispatched. The window reads it and forwards an intention — what "back" means is a question about the view on screen — and a view with nowhere to go ignores it.
  - **Three strips stop saying things nobody reads.** The terminal's status line held a sentence about the app, a seven-key cheat sheet and the pane's size; under them sat the one thing worth a row, and it is all that is left: rows of the pane hidden below the panel because a bigger client is attached, with the button that fixes it. The pane's own strip is one colour, the accent — `--info`, `--success` and `--warning` are the palette's words for a link, a pass and a caution, and spending them on chrome is how a warning stops being read as one. The top bar drops the live count and the ahead/behind pair; its middle is empty on purpose so the one thing that wants you has somewhere to appear. A pinned chip reads its own page rather than the last poll, and a finished agent tints its tab's name instead of adding a dot beside it.
  - **The phone's key bar latches.** Ctrl, Alt and Shift hold until the next key rather than needing a third hand, so `Ctrl+C`, `Alt+.` and the chords a terminal is actually driven by are one thumb each. The boards also open inside the floating bench as the same board rather than a second copy of one, growing to the view's content with an even margin and under the top bar.
  - **From outside this house, and the reason this release is not only ours.** Two holes where a server answer carried more than it meant to: an exception's text reaching the caller through a route's reply, and the same thing again through a wrapped answer that the first fix did not cover — found and closed by [@Dev-next-gen](https://github.com/Dev-next-gen), with the test that keeps them closed. And a project switch that left the composer opening chats in the checkout you had just left — [@takara159](https://github.com/takara159). Thank you both: outside eyes on a repository like this are worth more than the diffs say.
  - **Elsewhere**, the traffic reader says a token is expiring before it dies and where that will be read, the seat stops waking for agents it cannot reach or for reports that say nothing changed, the README carries a banner and the screenshots that already existed, and the actions group moved up a version.

- **v0.16.0** — **a review finishes on the phone.** It was three screens deep — the overview, push for the diff, back, push for the threads, back again to approve — and a review is a loop between those three, so every turn of it was a back gesture. Overview, Files and Threads are **segments of one screen** now; a pane is mounted the first time it is opened and never unmounted after, so it keeps its scroll, its expanded threads and its half-typed remark, and a pane you never open is never mounted at all. `/pr/diff` and `/pr/threads` still resolve, because a notification points at them, and render the same panes. **The conversations live on the line they are about**: a strip under the row of code — who, roughly what, how many replies — opening into the card that replies, resolves and applies a suggestion, with your own queued remarks drawn beside them in the review's own colour and a Remove to take one back. A thread whose lines have changed underneath it is not hung on whatever now carries that number; it sits above the file with the hunk it was written against, which by then is the only copy of those lines left anywhere. Applying a suggestion re-reads the diff as well as the threads, because it writes a commit to those very lines. And **Now, Source control and Settings are one `···` on every header** rather than a gear on the Inbox, so reaching Settings from a pull request is no longer a trip home and back.
  - **A body is markdown again.** Three screens printed one verbatim, each with a comment saying half-rendered markup reads worse than what somebody wrote — which is true of half a renderer, and cost the checklist every pull request here opens with, read as a wall of `- [x]`, plus a description cut off mid-word at character 1,200. Headings, lists with real tick boxes, tables and fenced blocks that scroll inside their own box while the page never does, and images fetched through the sidecar because GitHub's attachment host answers 404 without its token. The fold is by BLOCKS now and names what is behind it — "CU reference and 2 more" rather than "Show more"; an issue keeps no cap at all, because an issue is read rather than skimmed. Nothing is ever swallowed: an unknown construct renders as the text somebody typed, since the failure mode of a large parser is a blank where a paragraph was.
  - **The diff says what changed inside a line**, not only which line changed. A hunk that renames one identifier was two full-width bands and a game of spot-the-difference at eleven points. Token granularity, because a renamed identifier is one thing that changed and marking it letter by letter is confetti — and three refusals, which are the point: uneven runs are a deletion and an insertion rather than edits, two lines sharing too little are not a rewrite of each other and stay plain, and a middle longer than the table may be is marked whole. One implementation for both clients, and putting the desk's beside the phone's found a defect in each: the desk gave up entirely on a pair over 4,000 characters, and the phone called a line changed at both of its ends 14% similar to itself. It also **draws what is on screen** rather than the whole file — a four-hundred-line file was four hundred rows measured up front and measured again on every tap; measured over this week's own diff, 27 files flatten in 0.7ms and the largest is 426 rows of which 50 are mounted.
  - **The work item a pull request came from, whoever tracks it.** The desk read clickup.com and nothing else, so a repository linking Jira, Linear or a GitHub issue got no chip at all. Nine trackers by their own addresses — each pattern anchored on a host AND a path segment that means "an item", because a link to somebody's board is not a ticket — plus `Fixes #12`, which every public repository has and no tracker needs to be connected for, resolved against the pull request's own address. An id in a branch name is still a convention and is shown only when something connected could resolve it, never dressed in a tracker's colours; and an address belonging to ANOTHER tracker is never sent to be looked up in the board, where it is not found and reads as a card somebody deleted. On a machine that tracks work nowhere there is no chip, no gap and no placeholder.
  - **The phone's composer stops holding what you sent.** In `keys` the row along the bottom is a button whose text reads back what has gone down the wire, and nothing ever dropped that transcript — so a sent message stayed written in a rounded box at the bottom of the screen, which is the exact drawing of a field with your message still in it. Enter clears it, and only enter: Tab completes a line, up replaces it, Ctrl+C throws it away, and the pane is what knows what it says afterwards. The same path would have run a line TWICE when an IME commits the return as text rather than as an editor action. In line mode, where the field IS the pane's line, a pane still showing the prompt it was just handed no longer puts it back into a field that had just been emptied.
  - **Hygiene, and a lock rather than a promise.** Twenty-five comments across the app, the server, the phone and the landing page quoted private messages verbatim, and one carried a real person's name out of a chat notification. Every one now states the defect and how it was measured without saying who mentioned it. `server/test/private-content.test.ts` fails the build on a session link or a quoted conversation, and `CLAUDE.md` says plainly which of its rules that test cannot hold — a real name is not checkable, and pretending otherwise is worse than saying so.
  - **A seat for the orchestrator.** The agent that hands work out had no screen of its own: what it knew lived in a chat, so a report was pasted five times by hand and a worker stopped on a person was found only by looking. It has a view now that opens with what is waiting on you, a **tray** where every worker's report arrives in one fixed shape, a **queue** a person writes and the seat hands out, and a **brief** it gives every agent it puts to work — the half that was missing, since the seat's own rules govern the seat and nothing governed the people it employs. It can **ask for the one thing only a person can do** (`agentglass-agent need`), with what it costs, what it recommends and what would prove it done, and that ask stands on the screen until it is settled rather than scrolling away. An orchestrator already working can **adopt** the chair, and the strip says out loud that an adopted seat's powers are a claim and not a wall. A **gate** holds anything that leaves the machine — a push, a pull request, a comment, a review, a ticket, a message — behind an explicit switch in Settings rather than behind an agent's good manners. And `agentglass-agent field` answers who is idle, working or dead and since when in about twenty lines of text, because the thing reading it re-reads its whole context every turn and a pane capture per agent is the cost this exists to avoid.
  - **The inspector, for an agent that cannot see the screen.** The browser could hand an agent the page and not what the browser was saying about it. `inspect open | close | panel | zoom | shot`, plus `shot --with-inspector` for the page and the panel joined into one picture — console and network stay data through CDP, because a photograph of text costs a hundred times what the text does, and Elements, Sources, Performance, Memory and Application have no protocol answer at all, so their pixels are the only reading there is. Three things the pictures showed and no compilation would have: a view that has never been composited hands back a full-size rectangle of ONE colour and `isEmpty()` says no to that, so five pixels are checked and a frame that differs nowhere is a failure with no file; the name on a tab is not the panel's id for three of them, and `showPanel` on an id it does not know returns without switching, so the tab bar is read back rather than trusted; and a hidden view runs no timers, so a poll for the switch never advanced and every panel took twenty seconds to report a change that had already happened. The tab in the strip marks itself while an inspector is open on it.
  - **Filter the board by the card behind each pull request.** The rows showed which card a pull request came from and could not narrow by what that card said. The tracker's own builder, borrowed whole from the task view: `Where [field] [is / is not / is set / is not set] [values]`, several joined — so "everything except the ones already in QA" is a filter and not a scroll. Every status the workflow has is offered, drawn as the chip it is, rather than only the ones the loaded rows happen to be in, since "show me what I am NOT looking at" is exactly the question the absent ones answer. The row of facet pills is gone with it: eleven menus that could only say "is one of these" beside a builder that says that and three more things. Two defects it uncovered: the board draws its own two fetches and never looked at the filtered list at all, so the count moved and no lane did; and the card a row carries is only filled from a tracker board cached within the day, so on a stale cache the filter read an empty field while the chip was on screen — a reading older than five minutes is replaced by a live one now, and Refresh drops them, which is what Refresh always claimed to do.
  - **Elsewhere in the same cycle**, the alerts panel prices a **prompt cache you paid to rebuild**: a large cache creation after the previous cache-bearing turn in the same session, model and main/subagent lineage has expired, charged at the cache-write premium over a read rather than at the whole write. Six at most, dearest first — [#293](https://github.com/SirAllap/agentglass/issues/293). And **exact model prices, kept fresh**: `AGENTGLASS_PRICING_REFRESH=1` reads LiteLLM's published table at boot and daily and prices each model by its own id, with the bundled table as the offline fallback and your own `AGENTGLASS_PRICING` still authoritative over both. A rate the catalogue does not publish is read as ordinary input rather than as free, so a cached turn is never priced at nothing; Statistics says which table is in use and as of when — [#9](https://github.com/SirAllap/agentglass/issues/9)

- **v0.15.0** — the app learns to look after the agents, not only to show them. A **Lantern** view lights on the rail with the count of agents stopped on you and answers first: who needs you and why, in the notification's own words; every agent as a card — model, checkout and branch, what it is doing now (its own word, or its last tool call), what it was asked, commits over the base and files changed, calls, turns, errors, cost, and a countdown of the prompt cache. A **watch** re-reads the field every fifteen minutes and sends one notification when somebody is still stopped on you, a worker's window vanished, or claimed work has gone quiet; **Ask about the field** opens a chat with the field as its first message; **Schedule…** starts an agent later, at a time, with a prompt, in a checkout; **hand off** moves a conversation to another agent as a brief. **Named agents** — `agentglass-agent start / prompt / wait / read / send-keys / list / stop / schedule` — give a script a launcher and a liveness over the engine this app already owns, in a JSON shape an orchestrator's worker reads unchanged. The **Clone** stops a live agent that has gone quiet at twenty minutes instead of forty-five, sleeps until the session limit the CLI announces and resumes on its own, seeds a fresh worktree from `.worktreeinclude`, and comes back from a restart with every window split the way it was. The **terminal** gains **Pluck** (`Ctrl+Shift+Space`: the paths, links, hashes and ids on the screen, lettered, one key to paste) and **Ask about this** (a selection becomes a question to the agent in that pane). Pull-request cards count their **open threads** and offer to **nudge the reviewers**. The machine stays awake for **every** agent at work — the ones in your own terminals included — and starts in that mode. Underneath: the observer never counts itself, a bench tab's close can end what it runs, and the public repository describes its own features in its own terms.
  - **Security: the four doors an audit found, closed.** The browser's `upload` verb attached any absolute path on the machine to a page; it now resolves the real path, refuses `~/.ssh`, `~/.gnupg`, `~/.aws` and the app's own config by name, honours the disk kill switches, and admits only what the open project or the machine-search roots admit.
  - A plugin named `..` made install remove the config directory before anybody had consented; a plugin name is one segment, never dotted, and every remove or copy asserts its target is under the plugins root.
  - Worktree seeding followed symlink components and would have copied a linked `~/.ssh` into a checkout; it walks with `lstat`, refuses a link on either side, and seeds only files git ignores.
  - A plugin's token was graded as a paired device's and could answer a permission gate; plugins are their own kind of caller and never can, whatever scope they declare.
  - **The rest of that audit, one line each.** The named-agent start refuses every permission-shaped flag with a 400 that names it; the Clone's environment fence blanks webhooks, keys and tokens and points `gh` and git's credential helper at nothing; the judge runs in a private `0700` room rather than `/tmp`; outbound fetches for catalogues and tracker attachments refuse private addresses and follow redirects one checked hop at a time; the loopback status sink caps its free text and `done` needs the session that wrote the row; `gh api` fields are strings and node ids are validated; nvim is opened by argv, not a keystroke string; `fd` gets `--` before the query; the volume peek runs `busybox` or `alpine` or nothing; the preview routes judge the real path; tmux session names may not carry `:` or `.`; the record tables of unattended work honour `AGENTGLASS_RETENTION_DAYS=0`; the CLIs write session material `0600`, refuse to send the token over plaintext to a host that is not this machine, and the MCP docstring names its acting tools instead of denying them. Every fix carries a test that fails without it.
  - **macOS is not left behind.** Six places assumed Linux and failed quietly on a Mac: the engine's socket was built under a temp path too long for darwin, so it never started; restoring panes read `/proc` and `ps --ppid`; the bundled CLIs sat inside the `.app` and were on no agent's PATH (now prepended for every packaged build); self-update had no darwin branch; notifications called `notify-send` only; browser cookie sources knew only `~/.config` paths. Each is behind a seam a Linux test can drive as a Mac. The install table lists every artefact the release jobs build.
  - **The phone.** The request helper read every non-2xx as "this phone was disconnected" and logged out on a 409; only a 401 is a revocation now, it sends the paired host as `Origin` so writes pass the cross-origin gate, and it shows the sentence the server wrote. A pane opens typing straight through, per pane, and the choice survives every refresh; the live bar looks like the button it is. The Cards tab asks whichever tracker is connected rather than assuming one, and the terminal is offered only to a phone paired with full access.
  - **Hygiene.** Fixtures and comments no longer carry names from outside the project — reviewer logins, tracker product and list names, real card ids and pull-request numbers, a real login in example paths; every one is an invented stand-in of the same shape, and the tests that pinned the old words pin the new ones. Working notes written in diary voice about one machine left the tree.
  - **The Clone stops assuming one person's setup.** Shell history and setup cover zsh and bash beside fish (zsh's extended history format is parsed); the private-terms list lives beside the app's own config, `AGENTGLASS_PRIVATE_TERMS` names another, and a git hook's list at `~/.config/git/private-terms.txt` is honoured when the app's own is absent; the one deliberate override — "nothing here is private" — is a button that sends the consent flag the route reads; the brief speaks of "the owner", not a pronoun.
  - **Copy.** The Finder's preview and palette spoke another language in five places and the demo board had one prompt in it; all English now. The Lantern speaks of agents, not "the field"; the alarm card says Clone.

And every route that executes or mutates now refuses a caller with no `Origin`, which was 22 routes on the permissive gate against 5 on the strict one ([#469](https://github.com/SirAllap/agentglass/issues/469), [#488](https://github.com/SirAllap/agentglass/issues/488)).
- **v0.9.0** — the phone becomes a real application and the shell stops being fifteen months behind. A **native Android companion** replaces the one rendered in a browser tab, which could never finish a pairing handshake over a LAN address because `crypto.subtle` is secure-context only; it pairs, buzzes with the screen off, and holds a real tmux pane. The desktop moves to **Electron 43**, off a line that went EOL in April 2025, with the fuses proven in the packaged binary rather than in the config that asked for them, and the window backend read from the session instead of pinned to one that no longer draws on Wayland. The build stamp now names the *tree* that was packaged rather than whatever `HEAD` happened to be, so "does my installed app have that fix?" is answerable. On the server: the telemetry sinks stop being tokenless from anywhere but loopback, a proxy can no longer present itself as loopback, and an alert that could go missing on the way to you does not. The whole product carries one version number.
- **v0.8.0** — the redesign: the workspace stops being a modal over the dashboard and becomes the window itself, with the cockpit demoted to the first view on a rail you can reorder. Three new views arrive with it — **Tasks** (GitHub issues and your own list, with **Start →** to cut a worktree from an issue), a **Files** browser that opens into the app's own editor, and a **Ports & Resources** panel for what this machine is listening on and how hard it is working. The terminal learned to jump to the git/diff of whatever worktree its focused pane is in, and the desktop's own notifications are mirrored into the app so nothing is missed while it is fullscreen.
